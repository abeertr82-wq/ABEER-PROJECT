# المدينة المفقودة

لعبة استكشاف وألغاز عربية تعمل مباشرة في المتصفح، ولا تحتاج إلى خادم تطبيق أو تبعيات خارجية. الهدف هو جمع الأحجار والمفاتيح والأدوات، حل ألغاز الأبواب، ثم إعادة قلب المدينة إلى مكانه.

## التشغيل محليًا

يمكن فتح `index.html` مباشرة في المتصفح، أو تشغيل خادم ملفات بسيط لتجنب قيود بعض المتصفحات:

```bash
python3 -m http.server 4173
```

بعد ذلك افتح <http://localhost:4173>.

## التحكم

| الإجراء | سطح المكتب | اللمس |
|---|---|---|
| الحركة | `W A S D` أو الأسهم | عصا لمس افتراضية |
| التفاعل | `E` أو `Enter` أو `Space` | زر التفاعل |
| إغلاق اللوحات | `Escape` أو زر الإغلاق | زر الإغلاق |

تبدأ اللعبة بالصوت عند الضغط على **ابدأ الاستكشاف**، ويمكن كتمه من زر الصوت. تتغير المدينة بين النهار والليل، وبعض العناصر والألغاز لا تظهر أو لا تعمل إلا في الظلام.

## بنية المشروع

- `index.html`: الملف الوحيد للتطبيق واللعبة، وهو الاسم canonical للنشر.
- `scripts/check.sh`: فحص خفيف يتحقق من وجود الصفحة، سلامة JavaScript، والعناصر الأساسية.
- `.github/workflows/validate.yml`: يشغّل الفحص تلقائيًا عند كل push أو pull request.

تم حذف النسخة المكررة `index.HTML` لتجنب تعارضات النشر على الخوادم وأنظمة الملفات الحساسة لحالة الأحرف.

## الاختبار

شغّل الفحص من جذر المستودع:

```bash
bash scripts/check.sh
```

يفحص الأمر JavaScript المضمّن باستخدام `node --check` ويتأكد من وجود عناصر الواجهة التي تعتمد عليها اللعبة.

## النشر

للنشر على GitHub Pages أو أي استضافة ملفات ثابتة، استخدم جذر المستودع واجعل `index.html` صفحة الدخول. الخطوط تُحمّل من Google Fonts، بينما الصوت والرسومات مولّدان داخل الصفحة ولا يحتاجان إلى ملفات أصول إضافية.
