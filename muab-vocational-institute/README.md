# موقع معهد تدريب مهني مؤاب

واجهة عربية احترافية ومتجاوبة لمعهد تدريب مهني مؤاب، مبنية باستخدام React وVite وTailwind CSS.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

## محتوى الموقع

- صفحة افتتاحية تعريفية بالمعهد.
- برامج تدريبية تفاعلية.
- أقسام عن المعهد ولماذا مؤاب.
- نموذج اهتمام بالتسجيل يعمل داخل الصفحة.
- تصميم متجاوب للهواتف وأجهزة الكمبيوتر.

الموقع الأصلي الحالي في المستودع محفوظ كما هو، وهذا المشروع موجود داخل مجلد `muab-vocational-institute`.
